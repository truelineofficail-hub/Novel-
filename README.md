# 📖 Novel — A Story Told in Chapters

A single-page, scroll-driven storytelling website that presents a narrative as a "novel," complete with a day counter, prologue, and multi-arc chapter structure. Built as a creative web experience rather than a traditional blog — the page unfolds like a book, tracking a story across arcs, milestones, and key dates.

**🔗 Live Preview:** [truelineofficail-hub.github.io/Novel-](https://truelineofficail-hub.github.io/Novel-/)

---

## ⚠️ Disclaimer

All stories, characters, names, and events presented in this app are **fictional**. Any resemblance to real persons, places, or events is purely coincidental and used for creative/storytelling purposes only.

---

## ✨ Features

- **Day counter** — a running tally (e.g. *Day 000 / 1000*) that anchors the story in a timeline
- **Prologue** — an introductory section that sets up the story's premise and characters
- **Chaptered narrative** — the story is divided into numbered arcs/parts (e.g. *I. The Longest Distance*, *II. Above the Clouds*, *III. The Highest Ground*, etc.), each containing key beats and milestone dates
- **Character-driven storytelling** — dialogue-style excerpts and named characters carry the narrative forward
- **Milestone/date markers** — specific in-story dates highlight turning points in the plot
- **Single-page scroll experience** — no page reloads; the entire story lives on one continuously scrolling page

## 🚀 Getting Started

### View it online
Open the live preview link above — no installation needed.

### Run it locally
1. Clone the repository
   ```bash
   git clone https://github.com/truelineofficail-hub/Novel-.git
   ```
2. Move into the project folder
   ```bash
   cd Novel-
   ```
3. Open `index.html` in your browser, or serve it locally:
   ```bash
   npx serve .
   ```
   or use the **Live Server** extension in VS Code.
